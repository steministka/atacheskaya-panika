```
model/                     
├── compute_extended_features.py               расчет фичей

├── model_eeg.joblib                           веса модели без поведенческих признаков
├── pipeline_data_preparation.py               финализированная предобработка
├── pipeline_feature_extraction.py             пайплайн работы с фичами

├── prep_v2.py                                 предобработка
└── requirements.txt       внешние зависимости (обязательно прописать, иначе модель может не запуститься)
```

Папка `results` содержит **5 артефактов** в формате `.ipynb` (Jupyter Notebook).\
В этих ноутбуках полностью воспроизведены и подробно описаны полученные результаты: ключевые графики, статистические метрики, промежуточные и финальные выводы, а также полный ход решения.

---

## Список артефактов (ноутбуков)

### 1\. `1-exploration.ipynb`

- **Назначение:** Разведывательный анализ данных (EDA).
- **Содержимое:**
  - Визуализации ЭЭГ-сигналов (покой, таблицы Шульте).
  - Первичная статистика: длительность записей, частота дискретизации, пропуски, артефакты.
  - Анализ распределений по группам (норма, ПТСР, соматоформные).
  - Выявление аномалий и выбросов.
  - Первичные гипотезы о признаках, связанных с ПТСР.
  - Анализ доступных конфаундеров: возраст (где известен), пол, поведенческие показатели.

### 2\. `2-preprocessing.ipynb`

- **Назначение:** Предобработка сигнала ЭЭГ, проверка гипотез, обучение и тюнинг модели.
- **Содержимое:**
  - Алгоритмы фильтрации и очистки сигнала (режекция артефактов, нормализация).
  - Список и процесс генерации признаков (фичей) для обучения:
    - спектральная мощность по частотным диапазонам;
    - показатели функциональной связности;
    - параметры апериодического компонента спектра;
    - микросостояния;
    - поведенческие показатели выполнения таблиц Шульте.
  - Обучение модели и тюнинг гиперпараметров.
  - **Обязательно:** разбиение на уровне испытуемых (leave-one-subject-out), исключение утечки данных.
  - Сохранение модели в виде автономного модуля, который работает с исходными сырыми данными.
  - **Обязательно:** обоснование выбора признаков и их клиническая/физиологическая значимость.
  - Раздельная оценка качества модели с поведенческими признаками и без них.

### 3\. `3-model-inference.ipynb`

- **Назначение:** Инференс обученной модели.
- **Содержимое:**
  - Запуск модели, сохранённой в директории `model/`.
  - Реализация скрипта/модуля таким образом, чтобы организаторы могли запустить ваш код в изолированном окружении.
  - Расчёт финальных метрик:
    - ROC-AUC на паре ПТСР/контроль с бутстрэп-ДИ (2000 итераций);
    - сбалансированная точность;
    - специфичность на группах «нормальное старение» и «соматоформные расстройства» (доля ложноположительных ПТСР при пороге 0.5);
    - метрики отдельно по возрастным подгруппам (там, где возраст известен).
  - Формирование выходного CSV с колонками `subject_id, ptsd_probability`.

### 4\. `4-confounders-specificity.ipynb`

- **Назначение:** Контроль конфаундеров и анализ специфичности.
- **Содержимое:**
  - Попытка предсказать возраст по тем же признакам внутри контрольной группы.
  - Метрики модели отдельно по возрастным подгруппам.
  - Проверка, что оценка модели не сводится к одному поведенческому показателю (например, суммарному времени решения таблиц Шульте).
  - Анализ специфичности: проверка, что модель даёт низкую вероятность ПТСР на группах «нормальное старение» (65\+) и «соматоформные расстройства».
  - **Обязательно:** подробное описание и доказательная база всех представленных выводов.

### 5\. `5-bonus.ipynb` (дополнительная ветка)

- **Назначение:** Восстановление временной разметки стимулов и извлечение вызванных потенциалов.
- **Содержимое:**
  - Восстановление фазы стимульной решётки (метроном номинально 2 Гц, каждый восьмой стимул девиантный).
  - Определение положения девианта в цикле.
  - Извлечение компонентов автоматической обработки: MMN/P3a.

## Требования к репозиторию `model/`

- `model.py` — должен содержать:
  - объект использованной модели;
  - загрузку кэшированных (сохранённых) весов в эту модель.
- `requirements.txt` — обязателен, с указанием используемой версии Python и всех внешних зависимостей.
